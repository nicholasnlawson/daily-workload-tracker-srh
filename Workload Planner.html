Pharmacy Workload Planner

Builds the daily directorate workload table from Pharmacy Ward List and Review List reports.

Ward list for EMR reports

Click a ward code to copy it, or click Copy next to copy the wards one at a time in order, then paste into the EMR report generator (Ctrl+V). The next ward to copy is highlighted blue; copied wards turn green. The list comes from the Ward directory page.

Ward directory

Sets each ward's display name, specialty and directorate, the order of the workload table and the ward list for EMR reports. The Ward code must match the code printed on the reports exactly (e.g. EAU:1-3). Use the arrows to change the order. Changes take effect for everyone once saved as ward_directory.js in the Workload Planner folder, replacing the old file.

Critical medicines

Medicines flagged as CRITICAL MEDS for Hx patients. Names and aliases (e.g. brand names) are matched as whole words, in any case, in the review list drug name. Separate aliases with commas. Exceptions stop a matching prescription being flagged, e.g. Enoxaparin with Dose is at or below 40 MG. The drug name is the review list's drug name column; the full prescription adds the dose, directions and type (SCH, PRN, ONCE). Words are matched as whole words, any case; separate several with commas (any one of them counts). The list is sorted A–Z when saved. Changes take effect for everyone once saved as critical_meds.js in the Workload Planner folder, replacing the old file.

Drag the ward list and review list reports (PDF or text) here, or drag the whole folder.

Columns to show

Hx. = patients with no recognised status. Total is all of them; the hrs columns split them by time since admission (report date minus admit date/time), so Total also includes those admitted <18 hrs ago. UQ = Urgent Queries, Q = Outstanding Queries, PRI = Review Incomplete (PRI >24 hrs = PRI last updated more than 24 hrs before the report), TMR = Tech Meds Rec, PRC = Review Complete. Not r/v >1 week = patients with a status whose last review is more than 7 days before the report date. Unreviewed items come from the review list PDF: Total, and those prescribed more than 48 hrs / 7 days before the review list was run (>48 hrs includes the >7 days items); – means no review list was loaded for that ward. Boarders and the white boxes are typed in by hand.

Patient details (for checking; not copied)
Prints the patient details for the wards in the selected directorate, one ward per page.
